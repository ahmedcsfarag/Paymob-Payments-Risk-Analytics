# Paymob Payments & Risk Analytics

## 📌 Project Overview

This project focuses on analyzing payment transactions and merchant performance using Microsoft Excel.

The analysis provides insights into **merchant health, market performance, transaction trends, payment channels, and payment risks**, helping businesses monitor performance and make data-driven decisions.

---

## 🛠 Tool Used

- Microsoft Excel

---

## 🎯 Project Objectives

The analysis aims to:

- Monitor GMV and transaction performance
- Analyze merchant health and churn risk
- Compare performance across different markets
- Identify transaction failure patterns and reasons
- Analyze transaction trends, seasonality, and payment channels
- Track key payment and risk KPIs

---

## 📊 Dashboard

The project includes four interactive dashboards:

- 👤 **Merchant Performance** – focuses on merchant health, churn, and risk segmentation
- 🌍 **Market Performance** – analyzes GMV, success rates, and market contribution
- 📅 **Calendar Performance** – analyzes trends, growth, seasonality, and transaction timing
- 💳 **Transaction Performance** – focuses on payment success, failures, and transaction risk

---

## 🔍 Key Insights

The analysis helps identify:

- High-performing and at-risk merchants
- Leading markets by GMV and transaction performance
- Peak transaction periods and channel behavior
- Major payment failure reasons
- Growth and seasonality patterns

---

## 💼 Business Value

This project transforms raw payment data into actionable insights that can help businesses:

- Monitor payment performance
- Identify operational and payment risks
- Understand merchant and market behavior
- Support data-driven decision-making
